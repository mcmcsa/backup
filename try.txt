Make this page/system fully responsive so it works well on any device and screen size (mobile, tablet, laptop, and desktop).

Requirements:

The layout should automatically adjust to fit the screen width — no horizontal scrolling, 
no cut-off or overlapping content.
All buttons, inputs, and interactive elements should resize and

without needing the user to zoom in or out.

instead of fixed pixel widths, so the design isn't locked to one screen size.

at every screen size.
